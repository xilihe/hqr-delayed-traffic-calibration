# Final targeted diagnostics

These analyses are post-confirmation exploratory. They preserve the original frozen experiment and the complete major revision. No model is retrained and no full score/resource grid is repeated in this round. Both partitions share one network and the same sampled flows.

## Retained-result route

From the repository root, use Python with NumPy and Matplotlib (final rendering: Python 3.12, NumPy 2.5.4, Matplotlib 3.11.2):

```bash
python revisions/final-v1/scripts/independent_final_audit.py
python revisions/final-v1/scripts/build_final_tables_figures.py
```

The first command independently reconstructs all 192 risk-summary point values and 160 paired point contrasts from actual daily numerator/denominator CSV records, verifies attribution identities, the original freeze hash and the development-only ACI selection. It does not rerun classifiers or independently certify an external population. The second regenerates final tables and two figures from the retained CSV files. Empty manuscript/table/figure directories are created automatically where needed. Figures use conditional paired temporal intervals; model/audit cells are fixed repeated evaluations of the same traffic.

The known set, classifier and unknown population change together; attribution is associative.

Large score caches and derived NPZ intermediates are regenerated by the full route.
